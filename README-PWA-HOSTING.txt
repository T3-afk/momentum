MOMENTUM 15 — PWA / IPHONE EDITION

WHAT THIS IS
------------
This is a hosted Progressive Web App version of Momentum.
For iPhone installation, the files must be served from an HTTPS website.

FILES
-----
index.html              Momentum itself
manifest.webmanifest    App name/icon/install settings
sw.js                   Offline app cache/service worker
icon-180.png            iPhone Home Screen icon
icon-192.png             PWA icon
icon-512.png             Large PWA icon

IPHONE INSTALL
--------------
1. Upload this folder to any static HTTPS host.
2. Open the HTTPS address in Safari on your iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch Momentum using its Home Screen icon.

IMPORTANT
---------
- YouTube soundtrack playback needs internet access.
- iOS can require a user tap before media playback.
- Use Settings > Save Backup to export your Momentum data before changing hosts.
- Browser/PWA storage belongs to the specific website address, so changing the
  hosting domain creates a separate storage area unless you import a backup.
